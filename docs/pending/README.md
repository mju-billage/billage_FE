# 보류 항목

QA를 돌리다 지금 당장 끝낼 수 없는 것들을 모아둔 곳이다.
"누가 풀어줘야 하는가"를 기준으로 파일을 나눴다.

| 파일 | 내용 | 막는 쪽 |
|---|---|---|
| `backend.md` | 서버 응답이 바뀌어야 풀리는 것 | 백엔드 |
| `design.md` | 디자이너가 답해야 풀리는 것 | 디자인 |
| `cleanup.md` | 우리가 하면 되는데 미뤄둔 것 | 우리 |
| `login.md` | 로그인 화면 QA 진행 기록 | — |

## 쓰는 법

- 항목을 해결하면 그 자리에서 지우고, 커밋 해시를 `login.md` 같은 화면별
  기록에 남긴다. 여기에 "해결됨"으로 쌓아두지 않는다.
- 새 화면 QA를 시작하면 `<화면이름>.md`를 만든다. 화면 ID는
  `docs/screen-map.tsv`에서 찾는다.
- 막힌 이유와 "무엇이 오면 풀리는지"를 반드시 같이 적는다.
  그게 없으면 나중에 다시 조사해야 한다.

마지막 갱신: 2026-10-14 (가입 완료 화면 QA 기록 추가)
